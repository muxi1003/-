## 1. 结论

**有条件可行。**

纯文件布局适配就能跑起来（**不需要改脚本**），但：

1. **特征集会明显缩水**——49 窗集缺少 summary 侧约 50 列特征中的大部分；
2. **样本量只有 47**（73 集是 73），交叉验证结论会明显更弱；
3. **有一个必须先澄清的方法学限制**（见 §5）：这是**带监督的后处理校正**，不是无监督方法。

**建议：可以跑，但要事先约定"什么结果算成功、什么结果就该放弃"，避免事后挑数字。**

## 2. 校正器的工作原理（读代码所得）

| 环节 | 实现 |
|---|---|
| 输入 summary | `{input_root}/{output_prefix}_summary.csv`（默认 `paper_repro_summary.csv`，**67 列**） |
| 输入曲线 | **每个样本** `{input_root}/{video_id}/{output_prefix}_curve.csv`（硬编码目录布局） |
| 训练目标 | `target = clip(truth_count − peaks, −1, +1)` → 三分类 {−1, 0, +1} |
| 特征 | summary 全部列（排除 `video_id`/`truth_*`/含 `error` 的列）+ 21 个曲线派生特征 |
| 模型 | `RandomForestClassifier(n_estimators=200, max_depth=3, min_samples_leaf=4, class_weight="balanced")` |
| 交叉验证 | `StratifiedKFold`，折数 = `min(参数折数, 最小类样本数)` → **小类会自动压缩折数** |
| 应用 | 按预测的 residual 类别对 `peaks` 做 ±1 修正 |

**关键认识**：`safe_adjust_target` 把目标**截断在 ±1**，即**该方法最多只改 1 次呼吸**。
所以它天然是个"小幅修正器"，不可能产生大幅提升。

`Experiment/01_同口径消融/runs/20260909_v1/paired_predictions.csv` 的列中，

## 5. 必须先澄清的方法学限制（**重要**）

### 5.1 它是"带监督的后处理校正"，不是无监督方法

`target = truth_count − peaks` —— **训练目标直接来自人工真值**。

- 在 **out-of-fold CV** 下这是合法的（每折不用自己的真值），73 集的 0.9429/0.9373 就是这个口径；
- **但部署时没有真值**，所以它只能用于：
  - **离线批量修正**（需少量标注数据训练），或
  - 有真值的回顾性改进；
- **论文里必须写明这是"监督式后处理"，不能写成"自动提升精度的方法"**。

**这一点如果不说清，审稿人会直接指出**。

### 5.2 它最多只改 ±1 次呼吸

目标被 `clip(−1, 1)`，所以提升幅度天然受限。73 集上 MAE 从 1.9713 → 1.7757（nested），
正是"少量恰好错 1 次的样本被纠正"的量级。

### 5.3 迁移性风险：视频重叠

**49 个窗的视频全部是 73 视频的子集**（D005 已证）。

因此：
- ❌ **不能**"用 73 训练、49 测试"——那 49 个视频的短片段已在训练集里，属**同视频泄漏**；
- ✅ 只能做 **49/47 窗内的 OOF CV**（与该集自身口径一致），但 **n=47**；
- 若要完全干净，训练集须剔除这 49 个视频 → 只剩 24 个样本，**不可行**。

## 6. 我建议的实验设计与"事前判据"

若你同意开跑，建议按以下**预先固定**的设置执行，避免事后挑选：

| 项 | 设定 |
|---|---|
| 分析集 | R2 `lindian49` complete 的 **47 窗**（与 D006 一致） |
| 真值 | `RR = 60 × manual_breath_count / duration_seconds` |
| 基线（只跑一个） | **r20 固定**（忠实原文基线，用户已确认） |
| 同时报告 | F1G1P1（初稿主线）作为第二列，供对照 |
| 校正对象 | 基线预测的 `peaks` |
| CV | 与 73 集同口径：固定阈值 OOF + **nested 阈值 CV**（两者都报） |
| 随机种子 | 固定（`cv_random_state=42`, `model_random_state=4`） |
| **事前判据** | **nested CV 的 ΔMAE 95% 区间不跨 0 → 视为可行方向，值得继续；跨 0 → 判定该方向在 30 秒窗上不成立，停止投入** |

> **为什么不先看固定阈值 OOF 再决定**：73 集的经验就是固定阈值（0.9429）比 nested（0.9373）好看，
> 但 nested 才是诚实的。**先定判据，再看数字。**

## 7. 预期结果（诚实预判）

| 情形 | 概率（我的估计） | 说明 |
|---|---|---|
| nested CV 区间跨 0 | **较高** | 47 样本 + 特征缩水 → 统计功效低 |
| 点估计为正但区间宽 | 高 | 参考 73 集 nested 仅 +0.008 |
| 区间不跨 0 且为正 | 较低 | 若出现，是**很强的信号**，值得全力投入 |

**我的判断**：这个实验**值得跑**（成本低、能给出终局答案），
但**不应期待它能救活论文**。它的价值在于**判定"残差校正该继续还是该放弃"**——
这比继续在跨界面上试探更有价值。
