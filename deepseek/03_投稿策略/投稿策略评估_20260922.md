## 3. 初稿真正的病根（三条）

### 病根一：立意反了 —— 论文不能以"为什么不行"为主线

初稿的结构是：**发现内部有效 → 迁移到久福掉一半 → 分析为什么掉 → 结论是"计数好不等于事件好、来源门控不采用"**。

这在学术上是**诚实**的，但在二区方法刊的评审逻辑里，它踩了三个雷：

| 评审会怎么问 | 初稿现在能怎么答 |
|---|---|
| 你的方法是什么？ | "整曲线质量选择"，但它只在 §3.2 占了一小节 |
| 比之前的方法好在哪？ | **答不上来**（见病根二） |
| 你的创新贡献是什么？ | §5.4 自己写的是"拟形成的贡献""当前简单来源约束已被负结果否定"——**等于承认创新没做成** |

你引用的参考文献结构（问题→方法→创新→对比优势→贡献）正是方法刊的标准骨架。
**初稿把"贡献"写成了"没做成"，这在投稿时是致命的。**

### 病根二：**缺少"对原文方法"的公平对照**（这是最要命的一条）

我在数字核对里发现（详见 `01_初稿数字核对_20260922.md` §4）：

初稿用作"原路线"基线的 **F0G0P0 = 0.223799**，
但项目自己复现同类数据的结果是 **r20 固定 = 0.902657**、**B73-P = 0.946595**。

**F0G0P0 比项目自己的复现低了 0.65–0.72。**

原因在初稿 §3.3 自己写了：**P=0 用的是 `distance=6、prominence=0.05` 的简易峰规则**。
所以 F0G0P0 ≠ 原文方法，而是"**把整条后处理链关到最粗的配置**"。

后果：

- "R² 从 0.22 提到 0.83"里，**很大一部分是峰值规则从劣化配置恢复**，不能归功于整曲线选择；
- **全文没有一处"在同一批窗口、同一人工参考上，本文方法 vs 原文方法"的对照**；
- 这正是项目总记录 **N039 早就列出的首要缺项**：
  > "在同一视频、同一人工参考和时间窗口上比较原文复现、仅替换YOLO、仅改变曲线选择、仅加入短缺口处理、仅改变峰判定及完整方法"

**审稿人最可能的一句话是："你的基线被人为削弱了。"** 这句话一旦出现，全文结论都会受牵连。

### 病根三：创新点三缺一

初稿（沿用 N032）列的三个创新，逐个对照消融数据：

| 声称的创新 | 消融证据 | 判定 |
|---|---|---|

## 4. 被埋没的真贡献：F 的**稳健性**，不是 F 的**提升幅度**

把初稿表2 排开看（数据全部来自初稿，未新算）：

| 背景 | F0（同帧 max，≈原路线） | F1（整曲线选择） | 差距 |
|---|---:|---:|---:|
| **P0（粗峰规则）** | 0.223799 | **0.834292** | **+0.610** |
| **P1（正常峰规则）** | 0.604575 | 0.890902 | +0.286 |

**关键规律**：
- F0 对峰规则**极其敏感**：0.22 → 0.60（Δ0.38）
- F1 对峰规则**几乎不敏感**：0.83 → 0.89（Δ0.06）

这说明：**整曲线质量选择让整条管线摆脱了对峰值规则精细调参的依赖。**

这是一个**比"R² 提升多少"好得多**的贡献表述，理由：

1. 它**不依赖那条可疑的弱基线**（无论基线取 P0 还是 P1，结论都成立）；
2. 它可以用**配对区间**严格检验（8 组数据已经在手，**几乎零额外成本**）；
3. 它对应一个工程上真实的痛点：真实部署时峰值参数没法逐场重调；
4. 它比"我们的 R² 更高"更难被反驳。

> ⚠️ 这是 DeepSeek 基于初稿表2 的**推断**，项目记录中**未见**此表述。
> 采用前必须用原始逐窗预测做配对统计（bootstrap）验证，不能直接写进论文。

## 5. 按参考文献的标准骨架重排（我的推荐方案）

你要的骨架是：**问题 → 方法 → 创新点 → 与之前方法对比 → 贡献**。对照本文现状：

| 骨架要素 | 现状 | 需要补什么 |
|---|---|---|
| **问题** | ✅ 有：头部运动/遮挡下鼻孔 ROI 不稳，计数指标掩盖事件错误 | 没什么要补 |
| **方法** | 🟡 有，但被埋在 §3.2 | 把整曲线质量选择（含共识救援）**提为主线**，独立成节+公式+伪代码 |
| **创新点** | 🔴 三缺一，两个被自己否定 | **删掉 G**；**P 降为工程实现**；主打 F 的**稳健性** + 事件级评价协议 |
| **对比优势** | 🔴 **几乎没有** | **必须补**：同窗同参考下的原文方法复现对照 |
| **贡献** | 🔴 写成"没做成" | 改为三条正面贡献（见下） |
| **局限性** | ✅ 极其充分（跨场 0.42、温标未知、单人标注） | 保留，但**从主角降为限制章节** |

### 建议的贡献表述（三条，全部有据）

1. **方法**：提出**整条双鼻孔候选曲线的质量选择**（含候选计数共识救援），
   并证明其价值主要在**对峰值规则选择的稳健性**，而非单纯抬高 R²。
   *证据*：同输入 8 组消融 + 配对区间（表2，需补配对检验）。
2. **评价方法**：建立**事件级 + 覆盖 + 拒判**的联合评价协议（0.30 s 一对一匹配、完整参考中的拒判计 FN、部分事件不折算为整窗 RR），
   并证明**计数指标会掩盖事件错误**——总数完全一致的窗口（内部 9 / 久福 38）**全部**存在未匹配事件。
   *证据*：4345 个人工事件 / 320 窗。**这是一条很硬的贡献，且不依赖精度高低。**
3. **机制分析**：对跨牧场失效做**分层归因**（覆盖损失 572 FN / 来源支持下降 / 参考敏感性 / 缓存层已排除半径与后处理差异）。
   *证据*：N058/N059/N061，含配对区间。

> 注意：第 2 条是**本文目前最独特、最不可能被抢**的东西。
> 大多数呼吸率论文只报计数指标；本文有 4345 个逐事件人工标注 + 一套严格匹配协议，
> 能实证"**R²=0.89 的模型，事件 F1 只有 0.75，且总数一致的窗口里全都有错配的事件**"。
> 这本身就是对领域有意义的结论，且**与跨牧场精度好坏无关**。
