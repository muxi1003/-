## 1. 结论先行

**「本文方法优于原文方法」这一主张，在 R² 上不成立。**

在**同一批 49 个固定窗**上，原文忠实复现 **r20 固定 = 0.877195**，

## 3. 这对论文意味着什么

### 3.1 必须放弃的主张

| 主张 | 状态 |
|---|---|
| "本文方法显著优于原文方法（R²）" | ❌ **不成立**，ΔR² 在 49 窗为负、39 窗仅 +0.023 |
| "整曲线选择带来大幅计数改进" | ❌ 相对原文基线仅 +0.004～+0.028 |
| "F0G0P0 = 原路线" | ❌ **严重误导**。r20 固定才是原文基线，F0G0P0 低 0.64（49 窗） |

### 3.2 仍然站得住的主张

| 主张 | 依据 | 评价 |
|---|---|---|
| **计数指标掩盖事件错误** | 事件 F1 与计数 R² 严重不同步；总数一致窗口仍全有未匹配事件 | ✅ **不依赖是否优于原文** |
| **跨牧场失效分层归因** | 572 FN 来自拒判、来源支持下降、参考敏感性、缓存层已排除 | ✅ 诚实且完整 |
| **本文方法与原文方法在 R² 上等价，但……** | 见下 | 🟡 需先验证 |

### 3.3 一个可能仍然成立的差异化主张（**待验证**）

注意 F0 对峰值规则**极度敏感**（39 窗：P0 0.5617 → P1 0.7749，Δ+0.213；49 窗：0.2370 → 0.6167，Δ+0.380），
而 F1 相对不敏感（39 窗：0.8770 → 0.9303，Δ+0.053；49 窗：0.8325 → 0.8809，Δ+0.048）。

**但这条现在有一个致命的反证**：r20 固定（0.9027 / 0.8772）**高于 F0G0P1**（0.7749 / 0.6167），
说明 **F0 并不等于原文方法**——原文方法有它自己的融合与峰值处理，消融的 F0 只是"本项目管线关掉 F"。

因此"F 让系统对峰值参数不敏感"这句话，
**在没有确认 r20 固定的确切配置之前，不能写**（见 §4）。
