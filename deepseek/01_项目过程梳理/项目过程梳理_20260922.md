## 1. 一句话概括

用 **YOLO11n-Pose + 随机森林伪彩色温度映射 + 双鼻孔温度曲线** 从热红外视频估计奶牛呼吸率；
**内部开发集（林甸）计数指标可用，但迁移到另一牧场（久福）后大幅下降**；
项目近半年的工作重心已从"提升 R²"转向**弄清下降的机制、并约束结论边界**。

> 目录名 `yoloV8` 是历史命名，**当前网络是 YOLO11n-Pose**。

## 2. 研究背景与目标

| 项 | 内容 |
|---|---|
| 复现对象 | Chen 等，*Respiratory rate detection of dairy cows based on infrared thermography in head movement scenarios*，J. Thermal Biology, 2025, 130: 104154 |
| 核心目标 | 从奶牛鼻孔热红外序列估计**呼吸次数**与**呼吸率（RR, 次/分）** |
| 难点 | 鼻孔面积小、头部剧烈运动、侧面遮挡 → ROI 采到非鼻孔区域；时序缺失；热像显示方式影响 |
| 延伸目标 | 部署到已有巡检小车（ROS 2），实现到站停车测量 |
| 关键设备 | 热相机 FLIR ONE Edge Pro；车载电脑尚未到货 |
| 当前投稿目标 | 用户明确为**中科院二区**（N057） |

**定位演变**（值得注意）：项目从"复现 + 提升指标"，逐步转为"**跨牧场失效机制分析 + 可观测性约束的事件判定**"。
初稿第 5.4 节明确：随机森林、YOLO 版本替换、普通归一化、门控概念本身**都不作为原创声明**。

## 3. 技术链路（当前实际采用）

```
观看窗口与帧时间绑定
  → YOLO11n-Pose 鼻孔关键点检测
    → 双侧圆形 ROI（内部固定 r20；外部 16–24 像素尺度自适应）
      → BGR 随机森林 → 温度代理信号 f(B,G,R)
        → 双侧 min-max 归一化 → 左/右/均值/最大/最小候选曲线
          → 整条曲线质量选择（F）
            → MAF-3 平滑 + 既有峰值规则包（P）
              → 呼吸次数 N 与 RR = 60·N/D
                → 独立人工逐事件评价（0.30 s 一对一匹配）
```

**三个消融因素**（同输入、固定 r20 缓存、同 RF、同 MAF-3）：

| 因素 | 含义 |
|---|---|
| **F** | 整条候选曲线质量选择（含候选计数共识救援） |
| **G** | 短缺口（≤3 帧）真实 ROI 重取 |
| **P** | 既有峰值规则包（自适应显著度、浅峰合并、来源支持等） |

**曲线质量评分**（初稿式 3，总记录 C014 记录过 PPT 漏写）：

```
Q_c = Pmed_c + 2·A_c − 0.5·CV_c − 2·M_c
```
`Pmed` 峰显著度中位数、`A` 第 95 与第 5 百分位之差、`CV` 峰间隔变异系数、`M` 缺失/推断来源惩罚。
历史汇报中的 `2A−0.5CV−2M` **是不完整写法**。

**不属于主线、已回退的方案**：CoTracker/TAPIR 跟踪、TFA 时间对齐、运动/呼吸解耦、CBAM 注意力、P2 检测头、Butterworth 频谱、MAD 相位、事件级融合。

> 当前**内部采用结论仍是 B49-MA / B49-MP**。

### 5.2 林甸同口径消融（N054 E054-LD，47 个 R2 完整参考窗）

| 配置 | RR R² | MAE（次/min） | 事件 F1 |
|---|---:|---:|---:|
| F0G0P0 | 0.223799 | 5.3646 | 0.732537 |
| F0G1P1 | 0.604575 | 4.4271 | 0.744354 |
| F1G0P1 | 0.894273 | 2.9355 | 0.752527 |
| **F1G1P1**（当前核查基线） | **0.890902** | **2.9781** | **0.753076** |

**要点**：F 把计数 R² 从 0.224 拉到 0.834（F1G0P0），但**完整组合的事件 F1 相对 F0G0P0 只提高约 0.0205**。
→ **"计数变好"≠"逐次呼吸识别变准"**，这是全稿的核心论点。

### 5.3 跨牧场外测（久福）

| 编号 | 口径 | n | RR R² | RR MAE | 事件 F1 |
|---|---|---:|---:|---:|---:|
| E051-JF-COUNT（N051） | 计数配对交集 | 122 窗 / 97 牛号 | 0.193704 | 5.360656 | — |
| **E055-JF-R2（N055）** | 173 计数配对窗 | 173 | **0.419629** | **5.156069** | — |
| **E055-JF-R2（N055）** | 216 完整参考窗 | 216 | — | — | **0.492010** |

- E051 的 R² 95% 区间：`[-0.415316, 0.573786]`
- 216 窗事件：TP 1324 / FP 1028 / FN 1706；Precision 0.562925 / Recall 0.436964
- **572 个 FN 来自 43 个拒判窗，1134 个来自有输出窗** → 拒判是重要部分但**不能解释全部下降**

### 5.4 R3 同观察者重复标注复核（N059，23 个可用窗）

**预测完全冻结，只换人工参考**：

| 队列 | 配对窗 | R2 F1 | R3 F1 | 差值（95% 区间） |
|---|---:|---:|---:|---|
| 林甸 | 12 | 0.692180 | 0.810631 | +0.118452 `[0.051349, 0.179778]` |
| 久福 | 11 | 0.304933 | 0.362832 | +0.057899 `[-0.023836, 0.134362]` |

→ 这是**参考敏感性**，不是算法提升；且**未消除跨场差距**。

### 5.5 关键分解结论

| 结论 | 证据 |
|---|---|
| 计数完全一致 ≠ 事件一致 | 内部 9 个、久福 38 个"总数相同"的窗**全部**存在未匹配事件 |
| 慢呼吸不是主因 | 相同 RR 分层内误差仍大：20–40 组 MAE 2.3059 vs 4.8870；40–60 组 3.3078 vs 8.1429 |
| 参考范围窄不是主因 | 林甸 MSE 13.7818、久福 61.7341（约 4.48 倍）；若仅换方差，R² 应为约 0.8704 |
| 纯常量温标偏移不影响归一化 | 若 T′=aT+b（a>0）则 z′=z；但**不适用于整条管线**（有效性阈值、非线性映射） |
| F 模块在久福未完全失效但增益不显著 | 林甸 MAE 差 −1.4491 `[−2.8976, −0.2137]`；久福 −0.1734 `[−0.7368, 0.3646]`（**区间跨 0**） |

**从失败中学到的结构性判断**（散见于 N039/N056/N060/N061）：

- 跨场下降**不是单一原因**；已排除"只改半径/后处理即可解释"（N058 缓存统一对照）。
- **原始画面到预测峰的链路**中，51 个窗在 YOLO 之前就因时间戳长间隔被拒判，另 2 窗全 261 帧无检测（N061）——这些在 RR 指标里表现为"覆盖损失"。
- **算法拒判 ≠ 人工不可辨认**：R3 的 4 个拒判窗仍标出 59 个确认事件（N059）。
- 定位漏检**不能只靠调输入尺寸/阈值修复**（N062 的 27 次探针，R3-01 九次均无检测）。

## 11. 给后续工作的提示（DeepSeek 建议，非项目结论）

> 以下为整理过程中形成的操作建议，**不是**项目已登记的结论，采纳与否由你决定。

1. **指标引用前先锁基线 ID**。本项目最容易出错的地方不是算错，而是把不同快照的数字并列。建议任何汇报/写作先写清"n / 真值版本 / 时长版本 / 分析集"。
2. **T14 的下一步应优先做"可见性与漏检分离"**，而不是继续在已查看的久福上调参。总记录 N061/N062 已给出方向：区分"可见但算法漏检"与"本就不可观察"。
3. **2518 份 JSON 的审计价值可能高于继续用 36 帧调参**。若其中含可靠的人工鼻孔位置，可作为定位评测的独立参考——但需先核验来源、是否为完全人工标注（带 `score` 字段，存在自动标注可能）。
4. **人工事件相位是当前最大的单点不确定性**。在投入新方法前，先做不看预测的重复标注（观察者内一致性）性价比最高。
5. **初稿的证据边界已经写得很克制**，这是优点。若要提升竞争力，优先补的是"独立增益"证据，而非增加模块。
