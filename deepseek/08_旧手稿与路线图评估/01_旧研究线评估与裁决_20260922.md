## 3. 这条路线的真实优点

1. **真值干净**——用的是未调整的 `innovation_repro` 口径，不是 B73-P。
2. **验证层次多**——fixed OOF / nested / prefix-group 三层都报，且**如实报告**了 prefix-group 下 `ns` 组失败。
3. **统计规范**——配对 bootstrap CI、McNemar、Bland–Altman 都有。
4. **可解释性**——特征块消融，把增益归因到 peak-count 上下文与时频一致性。
5. **自我约束强**——手稿反复标注 truth-calibrated 是上限分析、rollback 只有 1 例、外部结果是 provisional。
6. **文档化程度高**——脚本、指标、bootstrap、病例清单全在仓库。

**这确实是一条认真做过的工作，不是"凑数"。**

## 4. 但它过不了 Q2 门槛，原因有三

### 4.1 根本约束没变：73 视频、单牧场、无身份/日期/相机元数据

roadmap 自己写的 Q2 gate 需要"real metadata, heat-stress context, frozen external validation"；
`Current Q2 readiness: **not_ready**`；`cow_id=73/73` 但**只有 71 个唯一值且来自视频编号**，
`ambient_temperature_c = 0/73`、`thi = 0/73`、`head_motion_score = 0/73`。

### 4.2 增益的本质是"±1 次呼吸的修正"，而基线已经 73/73 都在 1 次以内

- 基线 exact = 49/73，**73/73 都在 ±1 次内**；
- 全部工作是在把这 24 个 ±1 错误中的 10 个改对；
- 效果量：R² +0.023，MAE −0.68 bpm。

**这不是"方法大幅领先"，而是"在已经很准的基线上再抠一点"。** 审稿人会问这个增益值不值得一篇论文。

### 4.3 **最致命的问题：5 级流水线全部在同一批 73 个视频上设计**

实际架构是：

```
residual corrector → signal consensus → signal-aware residual → safe gate → (rollback probe)
```

**每一级都在这 73 个视频上做设计决策并选阈值。**

- `nested CV` 只嵌套了**阈值选择**，**没有嵌套架构搜索**；
- `prefix-group` 是**文件名前缀代理**，手稿自己承认"not verified animal or acquisition groups"；
- rollback guard 是**事后从错误分析里发现的**，只改 1 个视频（McNemar p=0.500）。

**所以那个 +0.023 的 R²（含架构搜索的选择偏差）无法被现有验证设计排除。**
这一点比"样本量小"更致命——**样本量小会被要求补实验，架构搜索未嵌套则会被直接质疑结论有效性。**

### 4.4 外部验证从未完成

- Jiufu 94 clips 是 **provisional**：单人标注、cohort 在方法开发中被看过；
- 双盲 A/B 包**已备好但从未执行**（`dual_annotation_progress=0/109`）；
- 且该 94-clip 队列**与当前 271 窗 R2 参考不是同一套**。

## 6. 我的建议：先做一件有界的测试，再决定是否转路线 C

### 6.1 不建议做的事

❌ **不要直接把旧稿改一改投出去。** 它自己设的 Q2 gate 没达到，且 §4.3 的架构搜索问题无解。

### 6.2 值得做的一件事

**把旧线的核心跨场思想——P2g「相对伪彩集合」——放到当前 271 窗 R2 参考上测一次。**

理由：

| 项 | 说明 |
|---|---|
| **为什么值得** | P2g 在旧队列上把跨场 R²从 **−0.86 拉到 +0.50**（ΔR²=+0.269，CI 不跨 0）。这是整个项目里**唯一一个大幅度的跨场改进**。 |
| **为什么没做过** | 当前外测走的是 RF 绝对温度代理（0.4196），**从未测过 P2g 的相对伪彩路径**。 |
| **成本** | 中等：需要把 P2g 的信号构造接到现有 271 窗缓存上；曲线已存在（`curve.csv`）。 |
| **判据（事前定）** | 在 271 窗 R2 参考上，**P2g 的 R² 若显著高于 0.4196 且配对 CI 不跨 0** → 论文有了真正的跨场方法贡献；**否则** → 转路线 C。 |

### 6.3 若测试失败 → 转路线 C

路线 C（**事件级评价协议**）仍是唯一不依赖"优于他法"的主张，且**不受 D004–D010 全部负结果影响**。

### 6.4 无论走哪条路，都要先做

| 优先 | 事项 |
|---|---|
| 1 | **在总记录登记 B73-P 使用调整真值**，不得作基线（见 D010） |
| 2 | **把旧线补进总记录**（P2g / safe gate / conformal / 选择性报告），并说明与当前外测的口径差异 |
| 3 | 排查还有哪些 `paper_repro_*` 文件继承了调整真值 |
