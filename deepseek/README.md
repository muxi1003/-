# `deepseek/` 目录说明

本目录存放 **DeepSeek 助手在本项目中生成与维护的文件**。

| 项目 | 约定 |
|---|---|
| 目录位置 | `E:/real/use_code/yoloV8/deepseek/` |
| 建立日期 | 2026-09-22，Asia/Shanghai |
| 组织方式 | **同一主题的文件放在同一子文件夹下**，文件夹按 `NN_主题名` 编号 |
| 日志入口 | [`deepseek_log.md`](deepseek_log.md)（持续追加，不覆盖历史） |
| 与项目总记录的关系 | `docs/cow_rr_project_log.md` 仍是**唯一项目总记录**；本目录是 DeepSeek 侧的工作产物与日志，不另建平行总账 |

## 编号约定

为避免与项目既有编号冲突，本目录使用独立前缀：

| 前缀 | 含义 | 归属 |
|---|---|---|
| `N###` | 聊天/工作节点 | 项目总记录（Codex 侧），本目录不新增 |
| `C###` | 更改事项 | 项目总记录，本目录不新增 |
| `T##` | 待办 | 项目总记录，本目录只引用 |
| **`D###`** | **DeepSeek 侧工作节点** | 本目录 [`deepseek_log.md`](deepseek_log.md) |

## 维护规则

1. 每个有意义的工作节点在 `deepseek_log.md` 追加一条 `D###` 记录，写明日期、来源、动作、改动文件、结果与后续。
2. 修改已有结论时**保留原条目**，新增条目说明旧值与新值，不静默覆盖。
3. 区分「项目总记录已登记的事实」「DeepSeek 的推断/建议」「待核实」三类表述，不编造实验、指标、命令或设备能力。
4. 不修改项目总记录、人工计数、算法、模型、导航与历史指标；如发现冲突，记录并提出，由用户决定。
5. 涉及指标时必须带基线 ID、样本数、真值/时长版本与分析集，遵守总记录第 1.2 节的「不得混淆」约束。
