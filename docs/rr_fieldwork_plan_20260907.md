# 奶牛热红外呼吸监测：新一轮牧场采集方案

日期：2026-09-07。用途：现场采集、标注和冻结测试的操作参考。

本方案中的数量、比例、距离和采样安排是针对当前项目的建议起点，不是期刊门槛、通用标准或已经完成的功效分析。最终设置应先通过小规模试采确认。

## 1. 本次采集要回答的问题

1. 头部转动、单鼻孔交替可见和短时遮挡时，算法能否保持准确的呼吸事件计数？
2. 鼻孔持续不可见时，系统能否识别信息不足，避免把缺失补成呼吸？
3. 不同距离和鼻孔图像尺度下，固定20像素ROI是否仍合适？
4. 更换牧场、日期或设备后，温度映射和计峰规则是否仍然适用？
5. 当前一次呼吸的残差究竟来自算法，还是人工计数和窗口边界定义？

优先补齐同步参考和观测条件，再扩大视频数量。原有73段和已参与调试的49段继续作为开发资料；新数据是否独立，以其是否参与模型、阈值或规则选择判断。

## 2. 一次拍摄应同时保留什么

| 数据 | 最低建议 | 作用 |
|---|---|---|
| 面部热红外原始长视频 | 每场次连续2至3分钟，保留原始文件和时间信息 | 算法输入，事后统一裁剪窗口 |
| 同步侧腹可见光视频 | 手机或相机固定机位，清楚显示胸腹呼吸起伏 | 独立于鼻孔温度曲线的人工参考 |
| 辐射测温数据 | 设备支持时保存逐帧温度矩阵或可导出温度的原生文件 | 绕开伪彩色反演误差，并验证映射模型 |
| 校准资料 | 当天每套设备设置对应的原始测温静态图、配置和检查记录 | 检查色彩映射和设备漂移 |
| 个体和场次信息 | 牧场、真实耳标、拍摄时间、原视频编号 | 分组验证和追溯 |
| 同步环境记录 | 鼻部附近代表位置的空气温度、相对湿度、风扇及喷淋状态 | 解释工况，后续进行环境分层 |
| 人工标注 | 呼吸事件时间、总次数、可见性和不确定性 | 统一真值，定位漏峰和多峰 |

普通热视频MP4不自动等于可测温视频；判断标准是能否从所保存文件导出逐帧逐像素温度。后缀仅是线索，需要实际导出验证。设备支持情况请按具体型号和软件版本核对。[2]

## 3. 先试采，再正式采集

建议试采8至10头牛、15至20场次，包含静止、自然转头、部分遮挡和不同距离。试采资料归入开发集。

当场至少完整检查3场次：

- 热视频、侧腹视频都能打开，持续时长足够，没有明显卡顿或重复帧。
- 在同一个30秒和60秒窗口内，侧腹能够可靠计数。
- 两路视频起止同步标记都能识别，漂移已检查。
- 热图上的鼻孔有足够的原生热像素，而不只是输出画面被放大得很清晰。
- 温度导出或固定色彩映射路径能够运行，鼻孔没有大面积饱和。
- 图像中的文字、十字测温点、色标和水印没有覆盖鼻孔ROI。

试采发现问题应先调整机位、参考画面或记录方式。正式测试开始前冻结处理规则。

## 4. 正式采集规模与划分

### 推荐起点

- 2个牧场，每场30至50头不同牛，共60至100头。
- 每头牛约2场次，每次连续2至3分钟；尽量分布于不同时间或不同日期。
- 每场覆盖约3至5个日期，包含早晨与下午等自然工况。
- 合计约120至200段长视频。30秒切片约480至1200段，但切片之间具有相关性。

以上规模便于规划人力，并不保证某个R²、统计显著性或录用结果。根据试采的误差方差、同牛相关性、预期改善和置信区间精度进一步估算样本量。增加不同牛和日期通常比反复拍同一头牛更有价值。

### 推荐划分

| 来源 | 用途 | 可否调参 |
|---|---|---|
| 历史资料和新一轮试采 | 开发、调试、制定计数协议 | 可以 |
| 牧场A正式资料 | 按牛分组的训练和内部验证 | 仅开发/训练折内 |
| 从未用于调试的牧场B正式资料 | 预先指定的外部测试 | 不可以用测试结果调参 |

若两个牧场都已被反复用于调试，新增拍摄可构成冻结后的新日期测试，但不要把它描述为完全未见过的牧场域。条件允许时增加第三个未接触牧场更清楚。

仅能去一个牧场时，预先留出不同牛，并尽量增加不同日期的测试场次；称为牛只/日期留出验证，不称为跨牧场验证。

同一头牛不能同时进入按牛划分的训练和测试。同一长视频的001、002、003切片、重叠窗口和不同长度版本必须属于同一组。不同牧场相同耳标用farm_id与cow_id联合区分。

如果要分别研究牧场变化和相机变化，尽量用同一台相机跨牧场采集，再在部分相同场景中比较第二台设备；每场只用一种不同设备时，牧场和设备影响无法单独分离。

## 5. 有目的地覆盖困难情形

主体数据使用事先定义的时间段和牛只选择规则连续采集，保留自然难度分布。可另外补拍困难场景，标记为challenge，单独报告；不要把人为增加的困难比例当成牧场实际发生率。

| 情形 | 现场拍摄重点 | 后续可验证的改进 |
|---|---|---|
| 双鼻孔清晰、头部较稳 | 保留完整周期和低干扰对照 | 原文基线、测温质量、基本计数 |
| 自然向左/右转头 | 完整保留双侧到单侧再到双侧的转换 | 双鼻孔质量融合、坐标滞后 |
| 短时局部遮挡 | 记录遮挡开始和恢复，而不是只拍恢复之后 | 保守短缺口修复 |
| 持续转身、鼻孔离开视野 | 热画面可失效，但同步侧腹应尽量清楚 | 不可观测识别、拒判与覆盖率 |
| 头部快速上下/左右运动 | 机位保持固定，区分相机抖动与牛头运动 | 运动伪峰、跟踪和配准失效分析 |
| 不同距离、鼻孔大小 | 同一头牛多个距离，但每段内尽量固定机位 | 固定ROI与尺度适应的比较 |
| 咀嚼、反刍、舔鼻、饮水后 | 记录行为和鼻部湿润情况 | 非呼吸周期干扰 |
| 不同自然呼吸频率 | 不同个体、时段和自然环境 | 检查低频/高频性能及规则适用范围 |

距离可以从约1米作为试采起点，再选择能清晰解析鼻孔的近、中、远三档；例如0.7、1.0、1.3米只是试采示例，受镜头、对焦和安全作业距离约束。必须记录鼻孔直径或鼻孔间距的像素尺度。导出画面中的20像素并不对应各设备相同的物理范围。

以自然行为为主，不通过惊吓、强行扭头或改变降温措施制造困难样本。记录现场喷淋、风扇和直射阳光，遵循牧场管理及单位动物研究要求。

## 6. 热成像设置与温度映射

### 可以保存逐帧测温数据时

- 同时保留原生测温数据和用于定位的可视化画面，并保存二者的空间对应关系。
- 记录原生热分辨率、输出分辨率、帧时间戳、设备型号、序列号、镜头、软件版本和模式。
- 保持对焦和测温量程合适。记录发射率、反射表观温度、距离、环境温湿度及其设定依据；这些会影响测温。[3]
- 按设备说明预热和校准，记录自动非均匀性校正/快门事件。不要为了连续画面盲目关闭设备所需校正。
- 如有可追溯黑体，在预期温区进行拍摄前后检查。它不替代鼻孔组织测温条件的处理。

### 只能保存伪彩色视频时

- 固定调色板、温标上下限、显示映射模式和输出尺寸；若设备无法锁定，保存逐帧色标和上下限，并将此问题列为预定评估因素。
- 关闭或固定会修改像素的局部增强、MSX轮廓叠加等显示效果，优先纯热模式；具体操作取决于设备。
- 自动对比度或直方图均衡可改变颜色分布，而底层温度未必改变，因此同一种颜色未必一直对应同一温度。[4]
- 每天、每台设备和每套设置单独保存带测温信息的原始静态图，用于检查映射。静态图与视频的渲染、对齐关系必须核对；邻近时间的照片不能冒充同步视频温度真值。
- 仅靠几张静态图不能证明整个视频映射正确。不能确认映射时，保留为相对热信号数据，并明确局限。
- 校准训练/验证应按图像或场次划分，不只随机拆同一图内高度相关的像素。
- 不直接沿用旧随机森林并假设跨相机、跨季节仍准确。新映射验证和任何适应步骤都应在测试前规定。

温度映射校准标签与呼吸次数标签是两种不同真值，分别管理。新相机测温路径和原文伪彩色路径的比较应使用相同视频窗口，单独报告前端改变的影响。

## 7. 同步参考与人工计数

### 同步侧腹视频

普通手机即可作为第一选择，建议固定机位、足够光照和稳定清晰的侧腹画面，可采用1080p/30fps作为试采设置。先实际验证是否能数清高频呼吸，不以标称分辨率代替检查。

热相机和手机需要起止同步，不能仅凭同时按录制。优先统一时钟或硬件同步；否则在两路画面中记录共同可见且不干扰牛的事件，并保存两路标记时间和时间转换关系。普通闪光不一定在纯热画面可见；只存在于RGB中的标记不能完成热/RGB同步。条件允许时做开头和结尾两个标记以检查时钟漂移。

对帧级比较，可将残余同步误差小于一个热帧作为试采目标；达不到时记录实测误差，并相应放宽或放弃事件级比较。保留原始帧时间戳，不通过补帧把8.7fps变成伪造的高帧率。

### 窗口与事件规则

- 原始采集连续2至3分钟，先定义固定窗口，再评分；保留每个窗口外前后数秒的上下文。
- 主参考增加60秒窗口，并保留30秒窗口与既有流程比较。在一项牛呼吸计数研究中，60秒计数与呼吸传感器一致性最好，30秒次之；这不意味着60秒必然解决剧烈运动。[1]
- 60秒内总次数不能直接除以2，作为某一个30秒窗口的次数；必须按实际对应区间计数。
- 先在试采中固定一个可重复识别的呼吸相位事件，例如一次完整起伏中的最大扩张时点；正式标注时所有视频使用同一协议。
- 建议保存每次事件时间戳，事件必须由上下文支持其为一次完整呼吸中的指定相位。窗口采用[start,end)，边界事件不重复计算；这是一种事件计数协议，不能与“仅计完全包含于窗口内的全周期”混用。
- 若坚持严格完整周期定义，则分别标注周期起止，统一相应纳入规则，并使算法端点规则一致。
- 保留人工原始标注版本，不因为模型多/少一次就直接修改真值。
- 侧腹参考可能与鼻孔热峰有相位差；逐事件配对前应在开发数据估计合理时延，不能要求同一帧峰值严格重合。

计算采用RR=60*N/T，T为实际对应窗口秒数。30秒误差一次对应2次/min，60秒误差一次对应1次/min。裁短到20秒以后必须重新按20秒的事件和参考评价，不能仍按30秒换算。

### 人手不足时

完整双人独立标注可以作为增强项，不把它作为本次采集的前提。最低可执行方案是：

1. 一位标注者在不看预测曲线、峰位置和模型误差的情况下完成全部计数。
2. 隔一段时间按随机顺序重数预定比例，例如20%至30%的片段，并复核全部不确定片段；记录首轮和复核值。
3. 条件允许时请第二人复核上述随机样本与争议样本，分开统计随机样本一致性和争议复核结果。
4. 仍有争议时填计数下限、上限和uncertain；不可计数填unreadable，总次数留空，不填0。

重复自己标注不等于独立双人一致性，只能反映部分标注重复性。

## 8. 质量和可见性：热输入与参考分别标记

热输入不可见不代表侧腹参考不可数，两者必须分开：

| 热鼻孔输入 | 侧腹参考 | 处理 |
|---|---|---|
| 清楚 | 清楚 | 正常RR准确性分析 |
| 缺失/严重运动 | 清楚 | 保留为困难输入，评价预测或拒判和覆盖率 |
| 清楚 | 不确定 | 保留数据，做真值敏感性分析 |
| 任意 | 无法计数 | 不进入有真值的RR误差计算，但计入采集流程与参考缺失统计 |

可见性区间记录left_only、right_only、both、neither和unknown；给每侧记录可见时长或最长缺失时长。这里“可见”是人工图像观察，不以YOLO有没有输出坐标代替。

运动粗评分可用0=基本稳定、1=轻度连续偏转、2=明显转动/频繁位置变化、3=快速大幅运动或长时间离开视野。它是本研究操作性量表，需要示例统一标准；不要假装是已验证的行业通用量表。比例和缺失时长保留连续数值，方便后续重新分层。

逐帧关键点标注优先覆盖转头前后、弱侧鼻孔、遮挡开始/结束及尺度变化。随机密集标注同一段相邻帧的价值有限。测试视频的关键点标签只能用于评价，不能回流检测器训练。

## 9. 文件及记录表

建议命名：farmA_cow0123_YYYYMMDDTHHMMSS_session01_thermal.ext；同步侧腹使用相同前缀加_reference.mp4。名称示例不代表真实采集记录。

- [场次记录表](rr_fieldwork_sessions_template_20260907.csv)：每段原始长视频一行。
- [窗口与人工计数表](rr_fieldwork_windows_template_20260907.csv)：每个30秒或60秒窗口一行。
- [事件与质量区间表](rr_fieldwork_events_template_20260907.csv)：每次呼吸或每个遮挡/运动区间一行。

### 场次表关键字段

farm_id为牧场；cow_id使用真实耳标；source_video_id是原始长视频；session_id为一次连续拍摄。subject_group_id建议为farm_id+cow_id。dataset_split使用pilot_development、train、validation、internal_test或external_test。cohort_type使用natural或challenge。

capture_start_iso8601示例格式为YYYY-MM-DDTHH:MM:SS+08:00。ambient_temperature_c和relative_humidity_percent填现场仪器值，environment_log_path关联持续记录；可从每10至30秒记录一次的试采设置起步。没有数据留空，不以地域天气补成牛舍实测。

native_thermal_fps为实际原生采集帧率，thermal_frame_timestamps_path关联时间戳。temperature_scale_mode填manual/auto/unknown；radiometric_available填true/false。camera_settings_path保存包含调色板、发射率、反射温度、增强模式和软件版本的配置说明。

sync_start_thermal_seconds等字段均以各自原文件开头为零点；标记时刻和残余同步误差分别保留。实际窗口以热视频时钟为统一基准，参考视频通过同步关系转换。

### 窗口表关键字段

window_start_seconds和window_end_seconds以原始热视频起点为零；manual_duration_seconds为实际计数区间时长。manual_rr_bpm可暂留空，之后由次数和时长计算。primary_rule_eligible依据预先规定的参考可靠性规则填，而不依据模型误差填。

first_count、repeat_count和manual_breath_count分别保留首次、复核和最终计数；没有复核时repeat_count留空。count_lower_bound与count_upper_bound记录不确定范围。input_left_visible_fraction等取0至1，时长字段单位为秒。

### 事件表关键字段

record_type使用breath_event、visibility_interval、motion_interval、behavior_interval、camera_artifact或reference_unreadable。起止均以原始热视频时钟为基准；单次事件的起止可取同一时刻。channel区分thermal_left、thermal_right、thermal_both、reference_flank和camera；reference_path指向实际用于判断的原文件。

## 10. 采完如何证明改进

1. 在同一批窗口上比较原文处理基线与候选流程；相同前端的后处理消融与更换设备/前端的比较分开。
2. 参数在开发集选定并保存模型与配置版本，测试预测生成后才用参考标签评分。
3. 同时报R²、MAE、RMSE、Bland-Altman、完全计数正确率、误差不超过一次比例和自动输出覆盖率。
4. 按运动、可见性、距离、真实呼吸频率、牧场分层，不只报全体均值。
5. R²取决于真值分布；覆盖真实工况的呼吸范围，但不为提高R²刻意挑极端牛。配合分层MAE解释。
6. 用牛只为主、保留其场次和窗口结构的重采样估计置信区间；不要把同一长视频的相邻切片当成独立样本。只有两个牧场时也不能把它当成已经充分刻画所有牧场差异。
7. 事先区分自然队列总体性能与困难补拍队列性能。拒判、原始采集失败和参考缺失都保留记录。
8. 测试表现差而继续调参后，该批资料已成为开发数据；需要另一批未用过的数据再做确认。

新增低温季节或低呼吸频率数据时，在开发阶段审查旧流程中的最小温度过滤、40至90次/min自适应范围和以帧数定义的峰间距。它们是已有实现的假设，不是新数据的纳入标准；不能因超出旧范围就删掉真实样本。以秒定义周期条件后，再按实际帧时间换算，避免沿用旧8.7fps参数。

## 11. 出发和离场检查

- 出发前：验证保存格式、实际导温、侧腹机位、同步方法、电量和容量，打印或离线保存记录表。
- 每场次：先登记真实牛号与设置，热/RGB同时记录起止标记，记录风扇、喷淋、行为和环境。
- 每天结束：抽查至少数段原始视频，检查时间戳和计数可读性；当日解决设置漂移。
- 离场前：原始文件至少两份独立备份；保留原名、文件校验值和配置。裁剪、压缩和转码都在工作副本上进行。

资源有限时的优先顺序：同步侧腹参考 > 原始热数据与固定设置 > 真实牛号和时间 > 困难场景 > 增加独立牛/日期 > 更复杂的设备与网络。
