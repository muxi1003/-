## 3. 指标与基线台账

### 3.1 口径定义

- RR决定系数：`R² = 1 - sum((y - y_hat)^2) / sum((y - mean(y))^2)`；真值没有变异或样本不足时不可定义，负值也应如实保留。
- Pearson相关系数的平方是另一个统计量，不能与上述R²互换，强相关不等于数值一致。
- RR单位为次/分；完整窗口通常按`60 * breath_count / duration_seconds`换算，必须明确真实窗口时长。
- 平均呼吸次数准确度沿用已有实验定义：逐视频`max(0, 1 - abs(pred - truth) / truth)`后取平均并乘100%；只在truth>0且有效时计算，零值/缺失需另行定义与计数。
- 完全计数正确率、误差不超过1次的比例、MAE、RMSE、覆盖率与R²一起看。该平均准确度不是公认统一命名的通用指标，论文必须列出公式。
- 下列值最初来自2026-09-07读取的已保存结果，不是新推理；2026-09-09的N035已按当前49窗标注复算B49-MA/B49-MP，结果一致。其他行本轮仅核对保存表，未重新确认所有权重/脚本的不可变快照，不称为当前部署性能或独立外部验证。

## 7. 后续更新协议与节点模板

### 7.1 更新规则

1. 本项目后续工作开始时，先读本文当前状态、最新节点、待办和用户备注。更新前重新读取受影响部分，避免覆盖用户刚写的内容。
2. 每个有意义的节点均记录：新需求、数据/标注变化、方法决定、代码/配置改动、训练/评估结果、回退、文档交付、设备确认或阻塞。普通重复“继续”没有新变化时，更新当前节点的续记，不虚构独立成果。
3. 实验结束或回复前完成记录，给出本地日期、稳定节点ID、状态、证据和下一步；更新页首“最近更新/最新节点”。尚未运行明确写未运行。
4. 修改已有结论时：保留原结论及其适用快照，新增更改ID说明旧值、新值、原因和影响。总览可更新，但不能抹掉历史。
5. 指标必须带基线ID、样本数、数据/真值版本、时长规则和分析集；外测、主分析、敏感性、truth辅助分别标记。
6. 文件改动记录具体绝对路径及对象，如函数、参数名、配置项或表列。只有概念讨论时明确“未改文件”，不编造命令、测试或性能。
7. 用户自己留下的备注优先保留；冲突通过更改表解决。若用户要求停止维护，记录该决定后停止，不建立平行总记录。
8. 维护发生在处理本项目相关任务时，不代表后台监控其他聊天、自动知道设备到货或定时运行实验；跨项目讨论不自动写入。
