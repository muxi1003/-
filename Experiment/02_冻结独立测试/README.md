## 已冻结不代表已获得完整可执行方法

`method_config.json`保存已有信号配置及ROI策略，基础配置的模型/输入路径有占位值，须由经验证的输入适配器绑定快照权重。禁止直接当作一个“已经能跑原始视频”的JSON启动文件。

已有49窗处理代码用于整理后的帧和温度表。新原始视频的时戳、图像尺寸、伪彩色色标必须先建立与该处理链一致的输入约定，并在内部样本上验证后冻结适配器。测试集人工呼吸计数不得用于选择这些参数。
