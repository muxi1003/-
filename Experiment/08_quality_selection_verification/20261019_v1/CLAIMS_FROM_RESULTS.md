# 结果支持范围与最终决定

日期：2026-10-19。对应冻结协议`PROTOCOL.md`，不是事前注册或独立确认。

## 决定

- `claim_supported = partial`。
- `approved_plan_route = uncertain`，证据仍不确定。
- `novelty_recommendation = PROCEED WITH CAUTION`：仅表示有限查新没有发现已明确包含本项目精确方法和受控结果的已发表论文，不表示达到期刊录用门槛。
- `review_independence = same-family`；`acceptance_status = provisional`；`integrity_status = not_formally_audited`。

主要47窗同补齐比较区间上界+0.635977，未通过继续投入判据；82窗MAE方向未反转，13窗不劣于训练组选出的固定Min。未出现47与82均不改善等明确数值停止条件，有限查新也未证明精确方法已被同文覆盖。因此按用户批准的三分路线归入“不确定”，不事后修改判据。

## 支持的表述

1. 在相同温度、窗口、参考、线性补齐与P0规则下，质量选择相对固定Max的MAE点估计下降：47窗-0.469857、82窗-0.147357次/分；区间均跨0。
2. 补齐单独作用不足以解释原组合的全部点估计改善。不能反过来说纯选择优势已稳定证实，也不能给出普遍因果贡献百分比。
3. 方法相对Chen有可核验的决策层级差异：由逐帧融合转为五种已有双鼻孔候选的整窗评分。但质量择优概念已有SQI/RQI先例。
4. 单病例集中、P3退化、完全计数下降和评分项移除的不一致，明确限定了当前方法的应用边界。

## 不支持的表述

- 质量选择稳定显著优于固定Max，或对头部剧烈运动普遍稳健。
- 所有四项评分均已证明必要，或移除幅值就应升级为新最佳算法。
- 与现有SQI/RQI方法相比已建立准确度优势，或者本研究首次提出质量选曲。
- 对Chen已发表R²直接比较即可算出本方法提升比例，或已完整复现其端到端系统。
- 13个YOLO验证组窗口构成未见RR确认，82窗构成82头独立牛，或插值填回了真实呼吸。
- 整窗离线选择已证明实时流式车载部署可行，或现有证据可保证中科院二区录用。
