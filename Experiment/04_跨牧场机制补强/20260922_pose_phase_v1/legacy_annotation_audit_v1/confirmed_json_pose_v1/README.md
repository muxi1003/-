# 最终人工核对 JSON 的隔离重建数据

## 来源与用途

2026-09-23用户明确：JSON由X-AnyLabeling自动辅助标注，经过人工检查，是最终人工核对版本；TXT为另一版人工标注。本目录选用最终JSON，不能据此将TXT描述为机器标注或错误真值。

本目录用于下一阶段鼻部框与双鼻孔关键点定位实验，未训练、未替换默认模型。它不是新的独立测试集，也不是已经取得的呼吸率改进。

## 文件说明

- `images/`：JSON内嵌图像优先，无损PNG；无内嵌图片时使用核验过的当前同名、同尺寸图像。后一类对应关系仍有证据局限。
- `labels/`：严格转换后的YOLO Pose标签，鼻部框和左、右鼻孔两个关键点，保留浮点坐标。无标注的另一侧保留不可见编码，不虚构位置。
- `manifest.csv`：逐帧来源、哈希、组号、折号、纳入/隔离状态及点数。
- `fold0.yaml`至`fold4.yaml`：五折训练配置及对应的训练/验证路径清单。
- `protocol.json`：用户确认、生成方法、来源限制及统计；实际数量以此文件为准。
- `verification.json`：逐图像像素、逐标签转换、分组互斥和隔离检查结果。

## 隔离的三个样本

- `bs177611_frame_000012`：鼻孔点存在但缺少鼻部框，不将其转换成负样本。
- `bs210974_frame_000012`、`bs210974_frame_000015`：内嵌图像重复且外部图像配对存疑，暂不进入训练。

原JSON、TXT、当前训练集、冻结模型和RR输出均保留，不覆盖。此前`grouped_rebuild_draft`保留当时尚未确认来源的历史状态，由本目录记录新的用户确认。

## 评估边界

同视频及去除字母前缀后数字标识相同的组不跨折；这不等于已经确认生物学牛身份。旧冻结模型可能见过这些源视频，不能用它初始化后再把内部折外指标称为独立泛化证据。久福已用于多轮诊断，新适配结果必须标为回顾性实验。

下一训练对照需固定初始化、预算和主评价阈值，报告可见帧无框率、鼻孔点落入人工区域比例、ROI范围偏差，再决定是否运行完整RR；不能只报告训练损失下降或挑选最好看的图片。
