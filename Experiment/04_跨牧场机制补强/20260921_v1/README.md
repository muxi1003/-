## 这轮已经完成什么

- 固定R2参考和封存预测，补充拒判/输出窗错误分解、FP/FN总数抵消、RR分层、R²分母诊断及六档事件容差敏感性。有效结果在analysis_v3；analysis和analysis_v2均中止、已标INVALID，不引用。
- 仅试一个新候选：既有来源保护从整窗下沉到事件上下文。内部F1 0.753076→0.751237；外部0.492010→0.401696。降低召回，不采用；不替换默认方法、不将部分事件计为完整RR。
- 补充核心模块F开关的同输入对照：内部MAE差值F开启−关闭为−1.449091次/min，95%区间[−2.897589,−0.213730]；久福为−0.173410，区间[−0.736842,0.364643]。久福未证明稳定增益，不等于模块完全失效。结果在fusion_transfer。
- 为12林甸+12久福建立新的R3复核页面及解码PTS，旧事件/次数不预填；原R2数据和页面不改。
- 继续完成固定r20、同后处理配置及统一观看时间网格的缓存对照。计数配对集合不变；林甸R²0.877521、久福0.417673，差距仍在。数据位于common_cached_r20，不声称已统一全部上游采集与YOLO推断来源。

## 为什么内部有效、换牧场下降

已确认：同输入下曲线选择改善内部计数，但事件收益小；同总数仍有错配。外部MSE显著增大，且拒判贡献572 FN、有输出窗仍有1134 FN。参考RR分布变了，但同RR层内误差仍大，不能只归因为慢呼吸。曲线选择外部MAE点估计只改善0.17次/min，区间跨0。

待验证：人工播放按Q的时间偏差、热峰和呼气相位的对应、解剖可见性与来源标签的关系、实际色盘/温标变化。来源门控负结果说明“非直接检测”不能直接等同于“无呼吸信息”。

仍有混杂：新增对照已统一缓存ROI半径、后处理和观看网格，但不是原视频像素重新提取，不能恢复林甸历史CFR丢失的原始物理时间。上游YOLO定位/推断来源、颜色编码及真实可见性差异未完全排除，不将剩余差距全部归因于牧场。

## 唯一需要你完成的下一步

打开review24/index.html，按review24/复核说明.md完成24窗暂停逐帧复核，再导出三张表和JSON到新目录。Q/W必须在暂停状态记录；左右方向键逐帧；空格播放/暂停，E起止不可观察区间，A/D换窗。新增窗级“相位依据”，只见热极值不冒称已确认生理呼气。

不要在复核时打开selection_key_DO_NOT_VIEW_DURING_REVIEW.csv或分析曲线。固定抽样含4个久福算法拒判窗，是针对机制的分层复核，不是总体可见性比例调查。原观察者重复标注不是第二观察者验证。完成前稿中A1—A3均保留“待补”，不自动宣布科学验证结束。
