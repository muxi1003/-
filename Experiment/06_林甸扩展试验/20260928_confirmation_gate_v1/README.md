## 3. 整30秒参考复核

`p2_reference_recheck.html`仅装入P2原先6个可评分完整窗的**空白复核工作区**；视频是既有30秒观看副本，无算法峰、旧事件及旧次数，浏览器缓存键与P2不同。`p2_reference_recheck_queue.csv`只有播放路径和哈希，不含旧真值。可隔一段时间由原标注者重看；若能由第二人复核更好，但单人重标不能称双人独立标注，且P2结果已知，不能恢复为首次盲测。

复核时必须逐窗覆盖0–30秒：鼻部全程可见，或鼻部离画时仍有连续、可逐次计数的胸腹/其他独立呼吸依据。后一种情况要在备注写明依据及对应时段。没有连续依据时，记录不可观察区间并选`partial`或`unobservable`，不得把只看见鼻子的呼吸总数乘以2当作整窗RR。页面新增“整30秒逐次计数依据”；缺依据或缺独立线索说明时不允许标`complete`。人工事件仍按呼气峰标，无法定位的事件标不确定，不凭算法峰补标。

请在不打开旧P2标注及预测的情况下完成复核，如实填标注者与预测暴露情况，导出三张CSV及JSON备份，**存入独立的R1目录**。导出后先核对完整状态、事件数、不可观察区间及旧/新计数差异；如计数不同，逐帧裁决并保留两版，不按哪版使算法误差更小选择。这个复核用于参考可靠性诊断，不把P2重新称为新的确认样本。

## 4. 扩充门槛

`p3_candidate_pool_unselected.csv`只列出P1/P2和旧73之外的82条剩余候选源视频，涉及59个不同文件名牛号；**没有锁定P3成员、切片、人工真值或运行RR**。正式扩充前须冻结新批次选源和分析集，按牛号/原视频/场次分组，先取得上述复核的整窗可计数经验；对新批次同样保持RR MAE主终点、F1次终点、30.0秒和四组规则不变。所有入组窗都报告参考可用/不可用，不因鼻部离画或结果不好悄悄换段。

后续筛查更正：这里的59是不同**文件名字段**，不能都叫已核实牛号。其中6个字段为非纯数字或多牛命名。P3 v1名单已在标注/预测前标无效并留存；另立`20260928_p3_pre_score_protocol_v2.md`，仅从76条纯数字字段来源锁定53个数字牛号，各选一源。此更正不改本目录的原候选池或P2历史输出。

若历史训练图像清单始终无法恢复，下一批同牧场资料可称“按现存训练目录及用户说明排除同编号牛的扩展评估”，不称训练成员已被不可变清单证明或独立跨场外测。要取得更强的未见数据证据，优先采集**训练结束之后**、有耳标/场次记录且整30秒有连续人工计数依据的新视频，并在看RR预测前封存选源、标注及排除理由。当前P2主结果未证实C1P1增益；后续不能通过事后挑子集覆盖这一结论。
