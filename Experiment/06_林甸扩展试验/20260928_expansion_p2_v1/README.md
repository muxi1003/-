# 林甸P2新增30秒标注批次

本批遵循[预先冻结的RR MAE协议](../20260928_p2_rr_mae_protocol.md)。`source_inventory.csv`重查原日期目录的293条时间戳候选；`selected_sources.csv`按路径哈希固定选16条，0807–0810各4条，文件名牛号互不重复且与P1八条及旧73原来源均无字节哈希重合。这个检查不等于YOLO训练集排查，也没有核对牧场实际牛身份。

`annotation_batch_v1/`中有16段可直接播放的WebM观看副本，15段来自原视频0–30秒，1段来自30–60秒；技术排除0。每条只选首个满足PTS连续条件的30秒窗，不按鼻孔可见性或呼吸次数重选。制片时未运行YOLO/RR预测，也未读取人工呼吸真值。`segments.csv`与`frame_time_map.csv`保存原MP4源帧及播放时间对应，后续推理必须回到原MP4像素。

标注入口：[index.html](annotation_batch_v1/index.html)。逐窗填写标注者、实际预测隐藏情况、确认的呼气峰或不确定事件、不可观察区间及状态。只有整窗可靠计数时标为`complete`；看不清不能填零次或另挑窗口。完成后把页面导出的三张CSV和JSON备份放在**单独的P2目录**，不要与P1同名导出文件混放；浏览器缓存不代替导出。16窗当前全部`pending`，**尚无RR MAE、R²或事件F1结果**。

核验：16/16观看副本已回读且帧数匹配；合计4227个原帧时间绑定，剪辑SHA-256与清单一致。Edge中16/16可加载，时长29.999–30.001秒，首条实播可前进；桌面及390px手机视口无横向溢出。页面截图`qa_desktop.png`、`qa_mobile.png`仅用于界面核验，不是鼻孔/呼吸标注。
