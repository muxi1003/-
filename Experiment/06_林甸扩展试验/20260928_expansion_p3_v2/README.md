## 冻结与核查

- 选源见`selected_sources.csv`和`freeze.json`，详细规则见`../20260928_p3_pre_score_protocol_v2.md`：82条未选池中76条来源的`n`后字段是纯数字，涉及53个不同文件名牛号；每牛固定一源，A/B只是标注工作分批。另6个非数字或多牛字段没有凭猜测纳入。先前v1名单因身份规则错误已标无效并留存，不能用于标注或评分。
- 每源只用第一个满足预定PTS连续性门槛的30.0秒窗口；两批均无技术排除。`segments.csv`、`frame_time_map.csv`记录原MP4、视频哈希、起止PTS、原帧与观看副本帧对应。A为7116帧，B为6856帧，合计13972帧；53个WebM都经编码后逐帧解码计数核对。
- 标注页不嵌入算法预测。新页设置“整30秒逐次计数依据”，无依据不能设complete；本轮先封存人工事件和不可观察区间，再做同输入四组RR评分。A/B完成前不能先看A批结果，不能按算法误差挑选或替换窗口。RR主终点为完整参考窗上C1P1−C0P0逐源配对MAE差，事件F1为次终点；全53源的参考可用率与技术/观察拒测都要报告。
