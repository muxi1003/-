运行日期：2026-09-29。算法输入为53份原MP4的原始BGR帧，经`models/best.pt`的YOLO关键点、冻结随机森林温度映射与固定20px双鼻孔ROI取得左右温度，再仅切换原文/质量选择融合与原文/约束峰规则四组。每源取预先锁定的PTS连续30.0秒窗，`RR=2N`次/分。完整输入、脚本、模型、参考哈希见`manifest.json`；`INCOMPLETE.txt`不存在，53段均已处理。此处是共同输入上的信号规则对照，不是Chen完整端到端复现。

## 冻结主分析

用户A/B导出原件归档于`../20260929_p3_reference_audit_v1/`。用户随后确认`211023`应为partial，结构化修订版及变更哈希归档于`../20260929_p3_reference_adjudicated_v1/`，原件不变。审计将53个固定来源分为24个整窗计数与逐峰时间均完整的主分析窗（A16/B8，524个人工事件）、2个仅有用户整窗次数声明而无可靠事件时间的事后计数窗、27个无完整30秒参考窗。**不能把24/53称为随机缺失或把这24窗外推到全部53窗。**

主终点是逐源配对的RR绝对误差差值：候选减C0P0，单位次/分；一个文件名牛号对应一源，95%区间为固定种子20260928、10000次有放回自助重采样。方向性支持需区间上界<0且次终点不恶化。结果：
